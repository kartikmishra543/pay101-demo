Questions Developers Ask

Who can get API access?

Access is subject to Pay101’s partner review and approval. Contact the team to discuss your business requirements.

Is there a test environment?

Contact the integration team to confirm test environment availability and approved testing access.

How long does approval take?

Approval timelines depend on business review and documentation requirements. Ask the team for an estimate.

Where do I get help?

Contact support@pay101.uk to discuss integration support.

Does Pay101 offer APIs for developers?

Yes. Pay101 offers PayIn and PayOut APIs for approved partners to connect payment collections and payouts to their websites, apps and business systems. Request API access to receive the integration guide and credentials after approval.

Is Pay101 a payout API provider?

Yes. Pay101 provides payout APIs that approved partners can use to send money to bank accounts. Supported payout modes and availability, including IMPS, NEFT and RTGS, are confirmed during onboarding.

How to integrate a payment gateway with Pay101?

Start by requesting API access. After business review and approval, the integration team shares credentials and documentation. Follow the guide to set up authentication, obtain server IP approval, implement payment requests and status checks, and complete integration testing before going live.

Can I automate payouts?

Yes. Approved partners can use the PayOut API to initiate payouts from their own systems. Automation should follow the integration guide and include authorization checks, duplicate-request handling and final status verification. Availability is subject to your approved account and supported services.

How do I know a payment or payout succeeded?

Receive the result on your server and confirm the final status using the documented verification or status-check API and your order ID. Do not treat a request being accepted or a customer returning to your website as proof of a successful transaction.

Are API requests secure?

Pay101 uses HTTPS for encrypted connections and token-based merchant authentication. Follow the approved documentation for any additional request encryption and security requirements. Keep credentials on your server and never expose them in browser code or public repositories.

Why do I need to get my server IP addresses approved?

Server IP approval helps restrict API access to authorized systems and adds protection against unauthorized requests. Submit the public outbound IP addresses of the servers making API calls, and coordinate changes with the integration team before switching servers.
